# AI-Powered-Digital-Twin-for-Smart-Battery-Management-in-Renewable-Microgrids

Explored how AI, especially CNN-based digital twins, can predict and optimize battery performance in renewable microgrids. By improving real-time SOH and SOC prediction, our work enables smarter, self-learning BMS to boost efficiency, stability, and overall energy resilience.
